Projects

Lunaa's Fishy Adventure

A 2D adventure game built in Java where players explore a tile-based world, collect hidden keys to unlock rooms, gather fish, and avoid enemies/hazards. Players must manage their health and collect all fish to complete the game, where their completion time will be recorded. The game uses object-oriented design for movement, collision detection, input handling, UI, objects, and map tiles.

Key Features

  • Tile-based movement and collision detection
  • Automated enemy and environmental hazard systems that can deplete health
  • Collectible items with various uses/functions
  • Object-Oriented architecture using modular Java classes

Basketball Shot Tracker

A JavaFX basketball shot tracking application that allows players to record makes and misses directly on a digital court. Shot locations are visually displayed and used to autmatically calculate shooting statistics including three pointers. The application also includes undo and reset controls for easily managing any errors made.

Key Features

  • Interactive court for recording shot locations, makes, and misses
  • Field goal and three point percentage calculation with live stat updates
  • Three point shot detection based on court position
  • Undo and reset functionality for maanging shot history
